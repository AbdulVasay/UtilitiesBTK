# UtilitiesBTK
Bahria Town Karachi Bills Calculator — Electricity (net meter / solar), Water and Maintenance.

**Live:** https://abdulvasay.github.io/UtilitiesBTK/

- Open `index.html` in a browser.
- Calculation logic: `js/billing-calc.js` (formulas explained in `CALCULATIONS.md`)
- UI and saving (localStorage): `js/app.js`
- Tests: `node --test tests/billing-calc.test.js`
- Bills saved by the old electric-only calculator (same browser) are imported automatically.
